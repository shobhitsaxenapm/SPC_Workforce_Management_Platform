# Product Overview

SPC Workforce Management Platform is a dedicated B2B SaaS platform built to manage client-placement staffing operations. It tracks the complete workforce deployment lifecycle:

`Client → Client Requirement → Job → Candidate → Onboarding → Employee → Client Deployment → Attendance/Timesheet → Billing → Offboarding`

The system partitions features into **Admin** modules, **HR** modules, and **Public** candidate pages.

---

## Key Modules

### 1. Dashboard Overview
Provides statistics on Total/Active HR users, Openings, and Candidates alongside growth charts, pipeline metrics, and sourcing breakdowns.

### 2. Candidate Recruitment & Parsing
Handles raw resume text pasting, PDF/DOCX resume file uploads, bulk resume parsing, JD matching & search, and recruitment pipeline stage transitions.

### 3. Onboarding & Document Verification
Runs token-based secure candidate document upload portals, manages document approvals/rejections, joining schedules, and candidate-to-employee database conversions.

### 4. HR Management & Activity Logging
Controls HR user creation, activation/deactivation, and logs all HR operational events inside an immutable activity timeline.

### 5. Contract Management
Supports fixed-deliverable and rate-based duration contract creation, renewal alerts, status tracking, and admin approval gates.

### 6. Job Desk & ATS
HR module for posting job openings, reviewing candidates via AI insights, exporting applications, and initiating onboarding workflows.

### 7. Public Careers Portal
Allows public guest candidates to view job listings, search descriptions, and submit resumes without account creation.
