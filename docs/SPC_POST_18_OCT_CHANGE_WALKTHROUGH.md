## 2. The 10 Candidate Parameters Matrix

| # | Parameter Name | Schema Field Key | Data Type | UI Display Location | Recruiter Screening Purpose |
| :-: | :--- | :--- | :--- | :--- | :--- |
| **1** | **Full Name** | `Candidate.fullName` | `string` (Required) | Candidate Overview, Table, Headers | Core verified candidate identity. |
| **2** | **Current Role** | `Candidate.currentRole` | `string` (Required) | Overview title, Table 'Current Role' column | Instant evaluation of functional seniority. |
| **3** | **Current Company** | `Candidate.currentCompany` | `string` (Optional) | Overview subtitle, Table subtitle badge | Identifies organizational background & pedigree. |
| **4** | **Total Experience** | `Candidate.totalExperience` | `string` ('4+ Years') | Overview badge, AI Scorecard pill | Validates minimum tenure qualification for JD. |
| **5** | **Email Address** | `Candidate.email` | `string` (Email regex) | Overview contact grid, Action link | Primary channel for interview and offer dispatches. |
| **6** | **Phone Number** | `Candidate.phone` | `string` (Phone regex) | Overview contact grid, Call/WhatsApp | Fast-response recruiter screening contact. |
| **7** | **Current Location** | `Candidate.currentLocation` | `string` (City, State) | Overview location pill, Table column | Evaluates commute feasibility and local availability. |
| **8** | **Willing to Relocate** | `Candidate.willingToRelocate` | `'Yes' \| 'No' \| 'Negotiable'` | Overview mobility badge | Critical qualifier for onsite/hybrid roles outside home city. |
| **9** | **Notice Period** | `Candidate.noticePeriod` | `'Immediate' \| '15-90 Days'` | Overview availability card, AI Scorecard | Prevents offer drops; aligns with client target start dates. |
| **10** | **Compensation Baseline** | `currentSalary` / `expectedSalary` | `string` (LPA, e.g. 28 / 35) | Overview compensation card & Billing Drawer | Assesses budget feasibility & calculates placement fees. |

## 3. Lifecycle Statuses, Commercial Models & Sourcing Taxonomy

| Entity / Dimension | Allowed Code Values (`src/types.ts`) | UI Display Label & Color | What Changed Post-18 Oct | State Transition Trigger |
| :--- | :--- | :--- | :--- | :--- |
| **Pipeline Stages** | `New`, `Screening`, `Interviewing`, `Selected`, `Offered`, `Hired`, `Joined`, `Rejected`, `Withdrawn` | 'Withdrawn' (Slate Gray)<br>'7d+ Dormant' (Amber Clock) | Added terminal 'Withdrawn' stage; added 7-day dormancy threshold warning flag. | Candidate voluntarily withdraws or application exceeds 7 days without recruiter activity. |
| **Job Statuses** | `Draft`, `Published`, `Paused`, `Closed`<br>*Timestamps*: `createdAt` vs `publishedAt` | 'Draft' (Gray)<br>'Published' (Green)<br>'Paused' (Amber)<br>'Closed' (Red) | Disambiguated creation date from publication date; supported republishing with audit modals. | Clicking 'Publish Job' sets `publishedAt` and live visibility; 'Unpublish' pauses the job. |
| **Commercial Hiring Models** | `Direct Hire`<br>`Contract / Deployment` | 'Direct Hire' (Blue pill)<br>'Contract' (Purple pill) | Introduced dual commercial engagement model decoupling staffing deployment from placement fees. | Configured during job creation or via `ConfigureHiringModelModal`. |
| **Placement Billing** | `Invoice Pending`<br>`Invoiced`<br>`Paid`<br>`Cancelled`<br>*Guarantee*: 90 Days active | 'Invoice Pending' (Amber)<br>'Invoiced' (Blue)<br>'Paid' (Green)<br>'82d Remaining' (Clock) | Built placement fee calculator (% of CTC or flat fee), invoice milestone tracker, and 90-day guarantee counter. | Candidate arrival confirmed via `ConfirmJoinedModal` initiates billing invoice and guarantee countdown. |
| **Interview Sequencing & Recommendations** | `Round 1`, `Round 2`, `Round 3`, `Final Round`<br>*Option A*: `Strong Yes`, `Yes`, `Neutral`, `No`, `Strong No` | Round Sequence badges<br>'Strong Yes' (Dark Green)<br>'Yes' (Light Green)<br>'Neutral' (Gray)<br>'No' (Red) | Multi-round progression tracking; tokenized external feedback portal; standardized Option A recommendations. | Round auto-advances upon recruiter outcome review; ratings submitted via `/interview-feedback/:token`. |
| **Sourcing Taxonomy** | `Career Portal`<br>`AI Match`<br>`Direct Sourced`<br>`Agency Referral`<br>`Client Referral`<br>`Internal Referral` | Standardized `SourceBadge`:<br>Career Portal (Purple)<br>AI Match (Emerald)<br>Direct (Blue)<br>Referrals (Amber/Indigo) | Universal taxonomy replacing scattered raw strings across Applicants, Matches, Pipeline, and Profile. | Automatically tagged upon inbound application, AI matching algorithm, or recruiter sourcing. |
